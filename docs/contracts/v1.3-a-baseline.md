## 3. Provider, worker, and review blockers

- Sandbox Chromium launch fails (headless-shell SEGV before app
  code; Firefox SIGABRT; WebKit launch-close), so PDF rendering,
  E2E execution, and production builds cannot run here. C verified
  all four engines plus a loopback-bind EPERM. D/G checkpoints
  reached FAILED/RENDER_FAILED after publishing analyses.

  obtainable here; every browser-click, PDF-visual, and
  Chromium-render leg needs a capable machine or CI. I must not
