## Fixture boundary

Production must never import `app/mockup/**` fixtures, components, or
`public/mockup/**` assets. The A1 suite statically scans `app/`
(except `app/mockup/`), `src/`, and `components/` for mockup imports
and fails on any hit. Tests under `tests/` may render the mockup for
inventory assertions only.
