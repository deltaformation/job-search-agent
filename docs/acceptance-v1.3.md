Named SQL probes below run with bound parameters. Capture before/after values; ΔQ=0 means identical selected values, not just row counts.

~~~sql
-- Q1: all generation effects for job
SELECT
 (SELECT COUNT(*) FROM generation_requests WHERE job_id=:job) AS requests,
 (SELECT COUNT(*) FROM work_items WHERE kind='TAILOR' AND job_id=:job) AS work,
 (SELECT COUNT(*) FROM resume_versions WHERE job_id=:job) AS versions,
 (SELECT COUNT(*) FROM resume_reviews rr JOIN resume_versions v ON v.id=rr.resume_version_id WHERE v.job_id=:job) AS reviews;
-- Q2: workspace CAS and byte identity
SELECT revision,profile_id,profile_version_id,extraction_id,focus_json,
 recommendation_hash,last_request_id,last_submitted_revision FROM tailoring_workspaces WHERE job_id=:job;
-- Q3: immutable input binding
SELECT r.id,r.payload_hash,r.selected_keywords_json,r.directives_text,
 i.workspace_revision,i.submit_hash,i.input_hash,i.candidate_snapshot_id,
 i.focus_json,i.recommendations_json,i.master_text_hash
FROM generation_requests r JOIN tailoring_request_inputs i ON i.request_id=r.id WHERE r.id=:request;
-- Q4: primary versus latest/application
SELECT j.status,j.row_version,j.active_resume_version_id,j.selected_resume_version_id,
 a.resume_version_id AS application_version,a.applied_at
FROM jobs j LEFT JOIN applications a ON a.job_id=j.id WHERE j.id=:job;
-- Q5: attempt/event identity
SELECT e.attempt_id,e.seq,e.stage,e.source,e.recorded_at,a.started_at,a.result
FROM generation_progress_events e JOIN work_attempts a ON a.id=e.attempt_id
WHERE e.request_id=:request ORDER BY a.attempt_number,e.seq;
-- Q6: publication uniqueness
SELECT
 (SELECT COUNT(*) FROM job_analyses WHERE generation_request_id=:request) AS analyses,
 (SELECT COUNT(*) FROM resume_versions WHERE generation_request_id=:request) AS versions,
 (SELECT COUNT(*) FROM resume_assessments WHERE request_id=:request) AS assessments;
-- Q7: exact selected PDF
SELECT v.id AS version_id,v.review_state,a.id AS artifact_id,a.sha256
FROM jobs j JOIN resume_versions v ON v.id=j.selected_resume_version_id
JOIN resume_artifacts a ON a.resume_version_id=v.id AND a.kind='PDF' WHERE j.id=:job;
-- Q8: all forbidden ownership/relational gaps
PRAGMA foreign_key_check;
-- Q9: workspace read must not create state
SELECT COUNT(*) AS rows FROM tailoring_workspaces WHERE job_id=:job;
~~~

Q4 column names must match canonical schema before running; this plan inspected applications.resume_version_id/applied_at. Hash bytes with existing canonicalJson/SHA256 functions; never compare unstable object key order.

Evidence cell format: date, revision/dirty-tree identity, exact command/result, safe fixture IDs/hashes, browser/PDF/live-provider gaps. States: OPEN/PASS/PARTIAL/FAIL/BLOCKED. Expected-failure specs in A do not pass future behavior. All required cells and U journeys must PASS for release closure; environment-blocked evidence stays open.
