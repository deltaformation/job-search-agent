only for migration evidence, behavioral-contract discovery, and the temporary
Python oracle.

It is not current product scope, architecture, project status, or agent
instruction. Paths and commands inside these historical files may be stale
after relocation. Start from [`../../PROJECT.md`](../../PROJECT.md) and use a
legacy document only when the assigned rebuild work order links to it.

removed so an agent cannot accidentally trigger deferred discovery/application
work from the active project surface.
